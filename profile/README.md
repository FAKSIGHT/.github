# FAKSIGHT

FAKSIGHT is a GitHub organization for security training labs, code snippet
collections and reverse-engineering examples.

## Public repositories

- [GOAD](https://github.com/FAKSIGHT/GOAD): game of active directory
- [AWSGoat](https://github.com/FAKSIGHT/AWSGoat): AWSGoat : A Damn Vulnerable AWS Infrastructure
- [AzureGoat](https://github.com/FAKSIGHT/AzureGoat): AzureGoat : A Damn Vulnerable Azure Infrastructure
- [vulnerable-code-snippets](https://github.com/FAKSIGHT/vulnerable-code-snippets): Twitter vulnerable snippets
- [Vulnerable-Code-Snippets2](https://github.com/FAKSIGHT/Vulnerable-Code-Snippets2): A small collection of vulnerable code snippets
- [exercice-cicd](https://github.com/FAKSIGHT/exercice-cicd): Docker Compose environment for a CI/CD exercise
- [Reverse-Introduction](https://github.com/FAKSIGHT/Reverse-Introduction): Small C programs compiled to 32-bit x86 for studying the generated assembly
- [Incident-Files](https://github.com/FAKSIGHT/Incident-Files): Repository for Incident-Files; see the code for details
